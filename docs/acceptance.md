# 本地验收

交付依据美团公开 V1–V3 架构与项目自己的验收清单。第 53 版账本有 **76 项通过、8 项范围外、1 项暂缓**。账本以原始 F01–F82 为基础，另列 D01–D03。逐项状态、准入条件和原文来源见 [验收清单](acceptance.json)。

## 真实项目案例

| 案例 | 覆盖的验收 |
| --- | --- |
| scikit-learn 公开分类与手写数字 | 测量冻结基线和候选、多轮计划、证据复用及独立复核。正式 Skill 经用户批准后实际复用、切换和回滚，两个版本均被另一实验项目的索引隔离。 |
| PyTorch examples / WikiText-2 | 接入原生训练与评分，执行多文件结构候选、独立重放与一次冻结测试。实际测试中拒绝将评分器写入候选可改范围。 |
| MAPIE 与 Optuna | 从项目目录发现真实任务，检查冻结指标和多目标取舍，覆盖两轮候选、独立重跑、最终留出。 |
| TabZilla / OpenML Sonar | 从陌生仓库履行资源补问，完成两轮结构候选、两次独立重放以及一次留出测试。验证 ROC AUC 为 0.763636，21 条留出样本的 ROC AUC 为 0.888889，两种口径各自记录。 |

上述为本地实测摘要。运行目录含角色输出、路径及实验数据，随本地档案保存。发布目录提供源码、配套测试、合成示例和可公开的项目来源。测试与空环境示例的重跑步骤见 [README](../README.md#五分钟验证安装) 和 [HTML 手册](index.html)。

发布整理时在独立 Linux x86_64 环境按锁文件安装，使用 Python 3.12.1 执行回归测试得到 **144 通过、2 跳过**。跳过项为 macOS 专用的沙箱测试。将发布 ZIP 解压到同一主机的另一绝对路径后，用全新的 Python 3.12.16 环境重新安装、预检并执行内置分类基线。验证准确率为 0.956140，ROC AUC 为 0.993056。

合成传感器例子也在新目录独立提交并运行。控制进程中断后使用同一研究目录继续，完成候选训练、独立复跑和最终冻结评测。验证准确率从基线 0.75 到 1.0，保留测试准确率为 1.0。该结果用于验证接入与恢复，样本为发布包内的合成数据。

线上训练平台、在线 A/B、发布回流及云端协作等属于此交付范围外。长时间有真实任务在途的无人值守验收暂缓。短时定时唤醒、在途训练恢复和分账都有独立验收记录。
